# Eficiência Energética

Projeto de site institucional sobre eficiência energética, sustentabilidade e redução de desperdícios em ambientes empresariais e industriais.

## Objetivo

Este projeto tem como foco apresentar:

- boas práticas para reduzir consumo de energia;
- informações sobre desperdício e consumo consciente;
- metas e indicadores de sustentabilidade;
- uma ferramenta simples para estimar consumo;
- informações sobre a equipe e canais de contato.

## Estrutura da pasta

- `index.html` — página inicial do site
- `praticas.html` — boas práticas e ações sustentáveis
- `consumo.html` — conteúdo sobre consumo e desperdício
- `metas.html` — metas e indicadores de eficiência
- `calculadora.html` — calculadora de consumo energético
- `contato.html` — página de contato
- `equipe.html` — apresentação da equipe
- `style.css` — estilos principais
- `stylePraticas.css`, `styleCalculadora.css`, `styleContato.css`, `styleMetas.css` — estilos específicos de cada página
- `acess/` — imagens e recursos visuais do projeto

## Como visualizar o projeto

Como o site é composto por páginas HTML estáticas, a forma mais simples de abrir é via um servidor local.

### Opção 1: Python

No diretório da pasta do projeto, execute:

```bash
python -m http.server 8000
```

Depois abra no navegador:

```text
http://localhost:8000/
```

### Opção 2: VS Code Live Server

- abra a pasta no VS Code;
- instale a extensão Live Server;
- clique com o botão direito em `index.html` e escolha "Open with Live Server".

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript (quando necessário em páginas específicas)
- Assets locais em pasta dedicada

## Observação

Este é um projeto estático, sem backend ou banco de dados. O foco principal está na apresentação visual e no conteúdo informativo sobre sustentabilidade e eficiência energética.
